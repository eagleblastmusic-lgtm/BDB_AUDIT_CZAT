# Full-path purpose dispatch variant review

Concrete construction of initial policy inputs exposes a representational gap in OD-021/OD-035. FULL_PATH_CONTEXT_PARAMETERS currently requires one dispatch entry per (purpose, governing SpecRevision), while METHOD_QUALIFICATION chooses exactly one method_type and CLAIM_RELATIVE_ASSESSMENT chooses exactly one assessment_kind_version. Thus one installed policy cannot simultaneously select the four mandatory assessor branches (finding axis, defect match, clean control and materiality). A profile-only dependency DAG and individual schema fixtures do not detect this missing cross-context expressiveness. The same limitation affects method-specific investigation contracts.

Relevant exact sources reviewed completely: Data 30 (materiality separate from collection and denominator preservation), 43 (prior execution intent and result), 48 (claim-relative independence), 68 (distinct implementation mutation and oracle challenge contracts and complete 2×2), 70 (preregistered bounded interaction cases), 184 (cross-layer conflict blocks freeze); OD-003 purpose predicates, OD-021 complete spec/purpose dispatch and OD-035 separate assessor output domains. Existing parameter grammars retain these distinct contexts; do not merge their result enums or infer a variant from arbitrary caller strings.

Selected owner-delegated OD-037 successor amendment: explicitly discriminate dispatch by independently derived purpose variant in addition to exact governing SpecRevision. METHOD variants are the existing fourteen finite method_type values derived from the prior subject ExperimentSpec. ASSESSOR variants are the four exact registered assessment keys derived from the actual subject contract; all other purposes use a single DEFAULT variant. Each complete spec/purpose/variant tuple has exactly one row and exact registered algorithm/parameter equality. Missing, duplicate, unknown or mismatched rows reject. Caller variant selectors cannot authorize dispatch. This preserves all sixteen purpose families and their existing wire contracts, rather than adding generic predicates or parallel authorities. No historical wire bytes change; the not-yet-frozen V2 context profile can carry the explicit versioned amendment.
