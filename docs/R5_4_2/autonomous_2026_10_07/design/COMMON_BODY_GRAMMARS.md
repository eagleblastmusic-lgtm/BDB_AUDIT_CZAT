# Common closed body grammar decisions

OWNER-DELEGATED DESIGN DECISION OD-005. These definitions resolve representation gaps without creating extra canonical authority. They are successor design inputs, not an in-place reinterpretation of any historical kind/version. Affected bodies/material refs must be versioned before freezing exact schemas. Already-qualified unchanged bodies keep their original wire constraints.

## Scalars, sets and finite tags

SafeInteger: integer in [−9007199254740991,9007199254740991], never boolean/float. UInt: SafeInteger>=0. Revision: SafeInteger>=1. Int32: [−2147483648,2147483647]. No signed-64 range extension: the earlier proposal's signed-64 wording conflicts with immutable BDB-CJSON-1 and is superseded here. ID(kind): `<exact wire kind>_<uuidv4 lowercase>`; field names such as risk_id/assessment_id do not select another digest kind. Code: `[A-Z][A-Z0-9_]{0,127}`. Text: 1..65536 Unicode scalar values, no normalization; explicitly nullable informational captures may use null. Lists max65536, semantic bodies max16MiB canonical UTF-8. Digest: exactly64 lowercase hex. No new identity algorithm.

TypedRef, RawRef, ExternalProfileRef, accepted HistoryCut, AcceptedHead and AcceptedEventRef retain the exact qualified predecessor representation. Kind/version is established jointly by wire kind and exact bound executable schema RawDigest; logical ID alone never selects a revision. A finite typed union names actual kind/version pairs; symbolic class names cannot be accepted as wire kinds. A HistoryCut is a value checked against history, not a newly synthesized object fact.

Reference sets use the inherited exact typed sort tuple `(kind, logical_id_or_empty, revision_digest, digest_profile, BDB-CJSON-1(schema_revision_ref))`, unless a new field explicitly uses tagged full-canonical-value ordering. This resolves the earlier proposals' conflicting full-JSON sorting wording without altering existing arrays. Commit immutable refs remain the original union-DAG topological sequence. Raw/profile/tagged union sets sort `(reference_tag,BDB-CJSON-1(full_ref))`. Text/code sets sort UTF-8 bytes; diagnostic/event sequences preserve captured order. No duplicate exact identity. Different schema identities with the same logical ID are different refs, not duplicate authority to merge.

ScopeSet: sorted nonempty exact TypedRefs to the finite active versions of surface_record, surface_key, invariant_revision, finding_claim_revision, coverage_obligation and scope_state_record. Empty scope cannot prove broad applicability. Where a body explicitly allows campaign-wide scope, its exact accepted inventory is an additional permitted target by that field's explicit contract; it is not added globally. Supporting/basis refs do not silently widen scope. Textual descriptions remain descriptions and never replace ScopeSet or known exact subject refs.

AuthorityRef uses the exact installation-authorized external principal/authority profile representation selected by TrustProfile, with exact principal/role/scope/issuer revision and no capability secret. An external authority pin is not a fabricated prior canonical fact. A field currently pretending it is a generic TypedRef/PRIOR_ACCEPTED_ONLY must have a successor reference contract that explicitly permits the installation-pinned representation. Principal identity and authority grant are distinct selected pins; caller possession of either encoding proves no authorization. Trusted control-plane checks occur at durable acceptance.

## Surface anchors

STATIC anchor is closed `{anchor_kind:"STATIC", member_path:CanonicalPOSIXPath, byte_offset:UInt, entry_kind:Code, discriminator:Text}`. Offset is zero-based in exact original source member bytes; bounds/member/source checked independently. RUNTIME anchor is closed `{anchor_kind:"RUNTIME", method:Code, route_pattern:Text, registration_origin:SourceAnchor, namespace:Code}`. SourceAnchor is closed `{source_manifest_ref:TypedRef(source_manifest), member_path:CanonicalPOSIXPath, start_byte:UInt, end_byte:UInt}`, with start<=end<=member length and exact source identity. Routes are captured canonical patterns from the exact collector capability; no heuristic route normalization establishes STABLE identity. Category codes are declared by the exact prior source/collector capability profile, not Python dictionaries. Unsupported/ambiguous anchor/category is PROVISIONAL and remains in unresolved accounting. SurfaceKey records identity only and is accepted before collector outputs; SurfaceRecord subsequently carries backward collector provenance. Its anchor/category/source must equal its referenced key.

CanonicalPOSIXPath for source-bound members/anchors/drift records: OD030 exact SOURCE_PATH_SHAPE, 1..512 Unicode scalar values, original hidden and Unicode names, nonempty segments, no `.`/`..`, backslash, leading/trailing slash or NUL. No case-fold/Unicode rewriting changes source identity; duplicate canonical aliases reject under the exact selected source profile. Generic package/transport paths retain the separately restricted ASCII grammar with initial alphanumeric. SourceDirectoryRef permits empty string only for the exact source-manifest root and otherwise selects the same source path shape. Actual execution independently resolves authorized directory membership and platform-safe containment; unsupported platform paths, drive-relative escape or outside-view symlink following reject without normalization or omission. A representable POSIX source name does not authorize using it as a host filesystem path.

## Contradictions and root causes

ContradictionPosition is closed `{claim_revision_ref:TypedRef(finding_claim_revision), statement:Text}`. Positions are sorted by full claim ref and statement bytes, no duplicates; each claim appears in the parent's complete claim_revision_refs and at least two distinct incompatible accepted claims/positions are required. Statements describe the asserted incompatibility; supporting/opposing qualified evidence remains separately bound by parent fields. Differences in failure assumptions/input environments are ordered Text descriptions of exact referenced evidence contexts; they establish no independent fact. required_falsifier is a prior installed purpose-specific METHOD contract pin, never executable supplied prose. Status is OPEN|TESTING|RESOLVED_SCOPED|RESOLVED_FULL|BLOCKED; resolved status requires prior exact resolution decision and scope equality. Future decision cannot resolve its input contradiction. Resolution produces a later immutable contradiction revision pointing to the prior decision.

RootCauseMembershipEdge retains §58's exact field spelling: closed `{finding_claim_revision_ref:TypedRef(finding_claim_revision), relation_role:SUPPORTS_CAUSE|CONTRIBUTES_TO_CAUSE|UNRESOLVED, scope:ScopeSet}`. Sort by `(full finding ref, relation_role, BDB-CJSON-1(scope))`, as §58 requires; complete typed refs are material. Repeated finding refs with different roles/scopes still require the pinned root-cause policy's explicit permission; absent permission rejects ambiguity. Edge membership never transfers severity or evidence strength. multi_causal_condition, when present, is Text describing the conjunction under exact scoped accepted membership/evidence, not an evaluated expression. Changed membership/condition/source creates a new revision and explicit backward predecessor refs. Historical root causes and findings never mutate.

ScopeKey is the closed tagged value `{scope_kind:"CANONICAL_SUBJECT",subject_ref:ScopeRef}` or `{scope_kind:"SOURCE_MEMBER",source_member:{source_manifest_ref,member_path}}`. It is not a mutable path authority: the latter binds exact accepted manifest membership. A ScopeStateRecord's optional scope_ref must match its selected exact subject; source-member scopes cannot claim a different canonical subject without independent accepted mapping. Same exact key identifies one denominator subject in a represented inventory. This closes an unspecified representation through a successor body; historical scope_key bytes retain their original reader.

AcceptedEventRef is exactly `{accepting_commit_hash:Digest,ordinal:UInt}`, matching §15 and §57. Event type and campaign are derived from the verified containing commit/event; they are not caller-selected duplicate fields. The ordinal is zero-based, in bounds, and the event must be accepted in the required cut. Contradiction status additionally includes REOPENED as §60 explicitly requires; reopening is a new immutable revision with prior predecessor and new evidence, never a mutation of the resolved revision.

## Execution/control and measurement structures

Positive/negative controls and falsifier requirements are exact prior ExperimentSpec refs in their explicit field-specific sets; a control result is a later accepted ExecutionResult ref. An ExperimentSpec cannot point to the future result of its own planned control. trigger/expected_safe_behavior/expected_buggy_behavior/falsification_condition remain bounded Text describing registered experimental intent; actual truth derives from authorized qualified observations/assessments. They cannot be evaluated as arbitrary Python/regex/expression text. ObservationPathRequirement is closed `{observation_kind:START|FINISH|MEASUREMENT|ACTIVATION|CLEANUP|RESET|CHANNEL_CAPTURE|EXTERNAL_WITNESS, capture_profile_ref:ExternalProfileRef, required:boolean}`. Captures match exact descriptor/source/producer context and profile. Profiles required for an experiment must be authorized before actual execution.

Environment fields filesystem_profile/network_profile/clock_profile/sandbox_profile, seed_profile and cleanup_spec are exact installed/planned ExternalProfileRefs to their field-specific closed contracts, not arbitrary dicts. environment/dependency/harness/fixture/context equality remains mandatory through intent→descriptor→capture→result→qualification. For cleanup/activation use finite exact observable equality from the separate raw-profile decision; unsupported scientific capture cannot receive default PASS.

LayerResult is closed `{layer:L1|L2|L3|L4|L5|L6|L7, result:PASS|FAIL|BLOCKED, reason_codes:Code[]}`. At most one per layer; ordered L1..L7; all applicable contract layers present. Overall PASS iff every required layer PASS. Any FAIL gives FAIL, otherwise missing/BLOCKED gives BLOCKED. Syntax/RawDigest validation is not L5 producer authority or L7 completion.

ModelState/ModelValue/SourceAnchor/ModelBound and reduced Rational retain the exact finite model/raw grammar and ADR rules. ModelBound is closed `{bound:STATES|TRANSITIONS|PATH_STEPS, limit:UInt}`; PATH_STEPS positive, all <=65536, sorted by bound. Model fidelity copies of declared omissions/assumptions/bounds must equal exact model raw, never caller-reduced scope. ImplementationAnchor refs are the closed prior SourceAnchor values; abstraction mapping refs are retained exact raw mapping, with complete symbol/transition correspondence.

## Compatibility, drift and transition proposals

Compatibility observed/expected result is a closed tagged transport observation `{outcome:ACCEPT|REJECT|BLOCKED, output_raw_ref:RawRef|null}`. Raw output is mandatory for material result payload and independently compared under exact fixture contract; missing output is explicitly null. Error-family codes remain optional only when no error exists. known_legacy_bug is boolean and requires an independently established expectation/hardening basis, never current-result inference. Counts are derived exact denominator partition; unqualified fixtures do not disappear. Preservation PASS and correctness PASS remain separate.

ChangedManifestMember is closed `{member_path:CanonicalPOSIXPath, change:ADDED|REMOVED|MODIFIED|TYPE_CHANGED}`; sorted unique path, exact diff of old/new accepted manifests. Optional dependency_profile_change is closed `{old_profile_ref:ExternalProfileRef, new_profile_ref:ExternalProfileRef}` and must independently differ with proved applicability consequences. No mtime/path cache/source-generation label substitutes for bytes.

TransitionProposal.allowed_next_transition is closed `{aggregate_kind:CAMPAIGN|STAGE_RUN|LANE_RUN|ATTEMPT, from_state:Code, to_state:Code, event_type:Code}` constrained to the exact pinned transition table. proposal_parent_head is AcceptedHead. expiry_or_single_use_policy is literal SINGLE_ACCEPTED_TRANSITION_AT_EXACT_PARENT; wall-clock expiry cannot create ordering authority. Proposal is not a minted executor capability, future approval or accepted transition. Accepted use requires prior checkpoint/gate/knowledge and current trusted actor eligibility.

## Version and migration obligation

This design resolves fields, not their historical authority. New closed representations that change canonical bytes/meaning/material refs create successor versions. References to changed versions are propagated through each affected parent's exact reference contract, including schemas/profiles/installation/bootstrap as needed. Propagation is a finite work queue, never implicit aliasing. Original kinds/versions remain historical readers with original exact schemas; fresh successor campaigns explicitly select qualified active versions. No retroactive bindings, approvals, equivalent-package acceptance or fabricated chronology.
