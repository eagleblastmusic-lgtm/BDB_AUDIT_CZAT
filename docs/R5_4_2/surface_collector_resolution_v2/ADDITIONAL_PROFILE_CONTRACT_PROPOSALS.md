DESIGN ONLY. These decisions are in scope because their exact keys are reachable in the approved mandatory Q2–N11 graph. They are not imported from runtime or overlays. No schemas or profile bytes are frozen here. Roles/layers/material refs/uniqueness/consumers/migration are explicitly specified per successor in SUCCESSOR_CONTRACT_PROPOSALS.json. ## Common wire and normalization rules

All new raw JSON profiles use the strict UTF-8/duplicate-key/integer/closed-object parser and 64 MiB bound defined by SURFACE_COLLECTOR_RECORD_JSON_V1. They have immutable ExternalProfileRef identity, installed before use, never their own digest in payload. All actual raw dependencies have a complete RawRef and survive accepted-history retention. Complete nested JSON value equality is required; no parser may filter errors or invent verdicts. Generic strings are Text, codes Code, integers UInt unless a narrower domain is listed. Named lists have 0..65536 entries unless a material ref specifies a positive minimum; required lists remain present when empty. Full-reference sets sort BDB-CJSON-1 bytes with duplicate rejection; observed diagnostic/event sequences retain raw order.

No role inference from an old RAW_EVIDENCE/EXPORT name is permitted. Semantic envelopes use their exact ObjectDigest wire kind/version. Raw payloads do not become TypedRefs. Semantic derivation does not independently establish trustworthy execution, truth, independence or assurance.

EXITED requires both captured times, finished >= started and real exit; BLOCKED has no exit/start/finish, and HARNESS_FAILURE has no fabricated exit (nullable captured times). ## Model-artifact and mapping grammar completion

MODEL_ARTIFACT_V1's prior prose did not specify a closed grammar. Propose exactly this raw JSON body: `{variables, initial_states, transitions, forbidden_states, abstraction_assumptions, bounds, omitted_states, fairness_assumptions, time_assumptions}`. Each field is required, including empty assumption lists. This is a finite transition-system representation; it does not define an unrestricted programming language or execute supplied code.

`variables` is a sorted unique list (1..256) of closed `{name:Code, domain:ModelValue[]}`. ModelValue is exactly boolean, BDB safe integer or Code string; value lists have 1..65536 entries and sort BDB-CJSON-1 bytes with duplicate rejection. A `ModelState` is a closed `{values:ModelValue[]}` in variables' order, exactly one allowed domain member for each variable. This ordering is semantic, never set-normalized. Product domain must have at most 65536 states; exceeding it rejects, never silently truncates. States compare exact typed values; true is not integer 1.

initial_states, forbidden_states and omitted_states are sorted unique ModelState sets. initial_states has 1..65536 entries; the others 0..65536. Every state lies in the exact product domain. transitions is a sorted unique list (0..65536) of closed `{transition_id:Code, from_state:ModelState, to_state:ModelState, source_anchors:SourceAnchor[]}`. A SourceAnchor is closed `{source_manifest_ref:TypedRef(source_manifest/1), member_path:CanonicalPOSIXPath, start_byte:UInt, end_byte:UInt}` with start <= end <= exact original raw member length. Source manifests are prior and exactly belong to the StateModel's source generation. All transition anchors are explicit prior-source membership, not model-local path authority. Every declared transition is included; no implied transitions or default stutter. A checker may follow only listed transitions.

abstraction_assumptions, fairness_assumptions and time_assumptions are ordered Text arrays retained exactly, 0..65536. They state limitations, never authorize adding undeclared transitions or changing the result. bounds is closed `{max_states:UInt, max_transitions:UInt, max_path_steps:UInt}` with states/transitions <=65536, max_path_steps 1..65536 and actual declared model within limits. Bounded reachability is the exact sequence of reachable sets R0=initial_states, R(n+1)=R(n) union all listed transitions from R(n), stopping at the declared bound or fixed point. A listed forbidden reachable state establishes a violation. No reached forbidden state supports only the declared finite/bounded model claim; it never proves implementation conformance, fairness or an omitted/unbounded behavior. Incomplete exploration is BLOCKED/UNKNOWN under the original qualification predicates, not MODEL_VERIFIED by truncation.

The mapping raw body is closed `{source_generation_ref:TypedRef(source_generation/1), variable_mappings, transition_mappings}`. Variable mapping is `{name:Code, source_anchors:SourceAnchor[]}`; transition mapping is `{transition_id:Code, source_anchors:SourceAnchor[]}`. Exactly one mapping per declared symbol/transition, no unknown/duplicate symbols; lists sorted by Code and anchors by full identity. Source generation and manifests must agree with StateModel's exact prior refs. This is a declared abstraction correspondence, not a semantic equivalence verdict; the original independent ModelFidelityAssessment must still check the mapping, assumptions and implementation applicability. No proof or fidelity result goes into its own future input artifact.

The capture profile and all required expected raw are installed/planned before execution and agree with descriptor/experiment cleanup specification. Semantic predicate is exactly equality of the selected trusted capture value to the declared expected value. This finite contract cannot reinterpret arbitrary tool prose as cleanup evidence. This is input/profile availability, not an undefined new scientific meaning.
